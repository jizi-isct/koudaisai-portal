# 用語集 (Glossary)

このドキュメントでは，プロジェクト内で使用される主要なドメイン用語を定義します．

## 組織・登場人物

| 用語           | 英語表記    | 定義・説明                                           |
|:-------------|:--------|:------------------------------------------------|
| **工大祭実行委員会** | JIZI    | 本システムの運営主体および管理者．Keycloakで管理されるアカウントを持つ．        |
| **団体**       | Group   | 本システムを利用する参加単位．大きく「参加団体」と「学内取材団体」に分かれる．         |
| **参加団体**     | Project | 模擬店，一般企画，ステージ企画などを実施する学内の団体．                    |
| **学内取材団体**   | Press   | 取材活動などを行う学内団体．企画団体とは独立した存在．                     |
| **ユーザー**     | User    | システムにログインする個々の利用者．通常，一つの団体には複数のユーザー（責任者など）が紐付く． |

### 企画種別 (Project Type)

| 用語         | 英語表記    | 説明                                    |
|:-----------|:--------|:--------------------------------------|
| **模擬店企画**  | Booth   | 屋外等で飲食物の販売や展示を行う企画．（団体ID例: `M-xxx`）   |
| **ステージ企画** | Stage   | 野外ステージ等でパフォーマンスを行う企画．（団体ID例: `S-xxx`） |
| **一般企画**   | General | 教室等での展示，発表，物販などを行う企画．（団体ID例: `I-xxx`） |
| **研究室企画**  | Labo    | 研究室の内容を一般向けに公開する企画．（団体ID例: `L-xxx`）   |

## 申請・承認 (Approval)

| 用語          | 英語表記             | 定義・説明                                                                    |
|:------------|:-----------------|:-------------------------------------------------------------------------|
| **承認申請**    | Approval Request | 団体が企画情報の変更などをJIZIに対して依頼するワークフロー．                                         |
| **申請ステータス** | Status           | 申請の状態．`Pending`（保留），`Approved`（承認済），`Rejected`（却下），`Closed`（取り下げ・終了）がある． |
| **申請事由**    | Issue Reason     | 団体が申請を行う際に記入する理由．                                                        |
| **却下事由**    | Approval Reason  | JIZIが申請を却下（または承認）する際に記入するフィードバック．                                        |

## コンテンツ管理

| 用語       | 英語表記             | 定義・説明                                                |
|:---------|:-----------------|:-----------------------------------------------------|
| **お知らせ** | Notification     | JIZIから団体または特定のユーザーに対して送られる通知．                        |
| **資料**   | Document         | 参加団体向けに配布されるPDFやMarkdown形式のファイル．                     |
| **フォーム** | Form             | アンケートや情報収集のための入力画面．外部（Googleフォーム等）と組み込みがある．          |
| **対象指定** | Target Specifier | お知らせや資料の公開範囲を制御するための仕組み．「全模擬店向け」「特定の団体ID向け」などの指定が可能． |

### 対象指定の特記事項

- **UserNologin**: ログインしていないユーザーでもアクセスできるAPI routeやコンテンツの制御に使用される指定．

## システム・技術用語

| 用語          | 英語表記           | 定義・説明                                                                   |
|:------------|:---------------|:------------------------------------------------------------------------|
| **団体ID**    | Group ID       | 各団体を一意に識別するID（例: `M-001`, `P-001`）．プレフィックスは概ね企画種別に基づくが，システム上の厳密な制約ではない． |
| **企画情報API** | plans-info-api | `api2025.jizi.jp` で提供される，既存の企画管理システム．本システムから一部情報を同期・操作する．               |
