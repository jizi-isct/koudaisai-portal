# プロジェクト概要

このプロジェクトは，名古屋工業大学の学園祭「工大祭」の団体（参加団体，報道団体など）と，運営主体である工大祭実行委員会（JIZI）の間のコミュニケーションを円滑にするためのポータルサイトです．

## 主な機能
- **団体管理**: 参加団体や報道団体の登録・管理．
- **申請・承認**: 企画情報の変更申請や，JIZIによる承認ワークフロー．
- **資料配布**: PDFやMarkdown形式での資料共有．
- **お知らせ**: 団体向けの通知機能．
- **フォーム**: 組み込みフォームや外部フォーム（Googleフォーム等）による情報収集．

## システム構成
本プロジェクトは Nx を使用した monorepo 構成を採用しています．

### コンポーネント
- **フロントエンド (`apps/web`)**
  - 技術: Next.js (TypeScript), Tailwind CSS
  - 役割: 団体向けダッシュボード，管理者（JIZI）向け管理画面の提供．
- **バックエンド (`apps/backend`)**
  - 技術: Rust (Axum), SeaORM
  - 役割: APIサーバーとして，DB操作，認証認可，外部サービス連携を担当．
- **ドキュメント (`docs`)**
  - OpenAPI定義（Swagger/Redoc用）などの設計資料．

### 外部サービス・インフラ
- **Keycloak**: ユーザー認証および認可（OIDC）．
  - 実行委員会（JIZI）のアカウントはKeycloakで一元管理されており，ログインできるユーザーは基本的に管理者とみなされます．
  - 詳細な権限管理は，Keycloak上のロール（roles）に基づいてアプリケーション側で制御されます．
- **PostgreSQL**: データの永続化．
- **S3 (Wasabi)**: PDF資料などのオブジェクトストレージ．
- **Discord**: 承認申請などの通知用．
- **SendGrid**: メール送信（Amazon SESに移行予定）．
- **外部企画情報API (`api2025.jizi.jp`)**: 既存の外部システムから企画情報を取得・連携するために使用します．

## 登場人物 (Roles)
- **団体 (Groups)**
  - **参加団体 (Project)**: 模擬店，教室展示，ステージ企画などを実施する一般の参加団体．
    - `Booth`: 模擬店企画
    - `Stage`: ステージ企画
    - `General`: 一般企画
    - `Labo`: 研究室公開企画
  - **学内取材団体 (Press)**: 学内の取材活動などを行う団体．
- **工大祭実行委員会 (JIZI)**
  - システムの運用，申請の承認，資料のアップロードなどを行う管理者です．
  - Keycloakロールによって，各委員に適切な操作権限が付与されます．

## デプロイ・運用
- **フロントエンド**: Next.js の静的書き出し（SSG）機能を利用し，`apps/web/out` に生成されたファイルを配信しています．
- **バックエンド**: Rust (Axum) サーバーとして稼働します．
