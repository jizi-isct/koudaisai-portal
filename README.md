# koudaisai-portal
[![Ask DeepWiki](https://deepwiki.com/badge.svg)](https://deepwiki.com/owner/repo)
工大祭ポータルは，参加団体などの団体が申請や資料の閲覧・JIZIとのコミュニケーション等を円滑に行えるようになることを目的に作られたサイトです．
フロントエンドとバックエンド，ドキュメントを含めた monorepo 構成を採用しています．
